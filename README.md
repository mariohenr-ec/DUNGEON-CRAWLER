# DUNGEON-CRAWLER
Projeto de jogo RPG em C.
Desenvolvido por: José Pedro, Mario Henrique e Vinicius Carreiro.
Sobre o jogo: RPG estilo Dungeon Crawler onde você controla um personagem que se aventura explorando uma masmorra de 3 andares até chegar no final boss. Seu personagem tem interalçãp em uma vila, podendo comprar equipamentos com npc para se fortalecer e desenvolver de acordo com o gosto do propio jogador. 
Seu objetivo é desenvolver o seu personagem ao explorar e lootear para se fortalecer e enfim derrota o final boss.
